# Algorithms in C++

A collection of classic algorithms and data structures implemented in C++.

## Contents

- **Sorting** — Bubble Sort, Merge Sort, Quick Sort, Heap Sort
- **Searching** — Binary Search, Linear Search
- **Graph Algorithms** — BFS, DFS, Dijkstra's Shortest Path, Bellman-Ford
- **Dynamic Programming** — Fibonacci, Knapsack, Longest Common Subsequence
- **Data Structures** — Linked List, Stack, Queue, Binary Tree, Hash Table

## Requirements

- C++17 or later
- A C++ compiler (e.g., `g++`, `clang++`)

## Build & Run

```bash
# Compile a single file
g++ -std=c++17 -O2 -o solution path/to/file.cpp

# Run the compiled binary
./solution
```
